# Animacja SVG — składanie opakowania

Samodzielna próbka portfolio wykonana do briefu animacji produktowej.

- czas pętli: 3 sekundy;
- technologia: czysty SVG, CSS i elementy SMIL;
- brak zewnętrznych bibliotek i fontów;
- obsługa `prefers-reduced-motion`;
- skalowanie bez utraty jakości.

**[Podgląd na żywo](https://an0th3r.github.io/ops-lab-portfolio/animation/)**

nie jest częścią publicznego repozytorium.
